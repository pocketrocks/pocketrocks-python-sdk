# Vendored bot-wire codec

This directory vendors the generated Python bot-wire package from the private
PocketRocks monorepo. The directory name carries no version on purpose: the
codec speaks every version the schema names and takes the protocol version as an
explicit argument. The ONE version this SDK speaks is pinned in
`src/pocketrocks/protocol.py` (`PROTOCOL_VERSION`, derived from
`constants.bot_wire_protocol_versions`); SDK code imports `encode_frame` /
`decode_frame` from there, never from here.

- Upstream source: `../pocketrocks/packages/shared/python/pocketrocks_bot_wire`
  (generated by `packages/shared/scripts/generateBotWire.mjs` from
  `packages/shared/protocol/botWire.schema.json`; layout in
  `packages/shared/src/wireFormat.md`).
- Protocol version the SDK speaks: `3` (`paymentRule` on `gameSetup`, signed
  zigzag chart cells, two reserved presence slots). The codec also still
  contains the v2 layout because upstream generates both; the SDK never
  negotiates it.
- Golden fixtures: `tests/fixtures/bot_wire_v3.json` and
  `tests/fixtures/bot_wire_primitives.json` are byte copies of upstream's
  `packages/shared/testFixtures/botWireV3.json` / `botWirePrimitives.json`.
  Both codecs assert against the same bytes (`tests/test_protocol_wire_v3.py`).

## Sync procedure

1. Copy `codec.py`, `types.py`, `reconstruction.py`, `constants.py` from the
   upstream path over the files here, and refresh the two golden fixtures.
2. Re-apply the SDK adaptations (upstream targets a plain interpreter; this
   repo runs `mypy --strict` and `ruff`). Each adapted file says so under its
   generated-code header. No behavioural edits are allowed — if the codec needs
   to change, change it upstream and regenerate.
   - `codec.py`: `from __future__ import annotations`; `Literal`/`cast` import;
     `CommonEvent`, `Frame`, `PaymentRule` imported from `.types`; return/param
     annotations on `_assert_protocol_version` (`cast(int, ...)`),
     `_encode_event`, `encode_frame`, `_decode_event`, `_decode_events`,
     `decode_frame`; `payment_rule: PaymentRule` via a `decoded_rule` local plus
     `cast`; `value_chart` cast to the 6-tuple; `frame: Frame` and
     `decision_kind: Literal[...]` declarations in `decode_frame`.
   - `reconstruction.py`: `from typing import cast`; `owned: list[list[int]]`;
     `requirement = cast(list[int], definition["requirement"])`.
   - `types.py`, `constants.py`: formatting only.
   - `__init__.py` is SDK-owned (explicit exports instead of upstream's
     `from .types import *`). Add any new public name there.
3. `uv run ruff format src/pocketrocks/internal/bot_wire && uv run ruff check
   src/pocketrocks/internal/bot_wire && uv run mypy src tests`.
4. If `ReconstructedDecisionContext` gained a field, add the same field to the
   public `DecisionContext` in `src/pocketrocks/types.py` in the same change —
   `protocol.build_decision_context` copies by name and raises on a mismatch
   (`tests/test_protocol.py` pins this).
5. If the schema's version set changed, update `PROTOCOL_VERSION` in
   `src/pocketrocks/protocol.py`, the README's compatibility section, and
   `.env.example`. Bump `__version__`.
6. `uv run pytest` — the golden-fixture tests must pass byte for byte.
